# Sinc

Смотрим вместе. Даже если вы в разных городах.

Sinc — комнаты для совместного просмотра на iOS и Android. У каждого свой телефон и свой звук. Сервер не раздаёт видео: он хранит одно состояние воспроизведения и рассылает команды.

Два режима:

- **Native Watch.** Прямая ссылка MP4/HLS или свой файл. Видео играет внутри Sinc через `expo-video`, play/pause/seek синхронизируются автоматически.
- **External Service Watch.** Кинопоиск, Okko, IVI и другие. Sinc не воспроизводит, не скачивает и не обходит их контент. Человек сам открывает фильм в официальном приложении. Sinc показывает общий таймер, команды «начать / пауза / перемотайте на…», чат и реакции.

DRM-потоки и страницы каталогов в плеер не принимаются.

## Состав

- `apps/mobile` — Expo SDK 58, Expo Router, NativeWind, Zustand, TanStack Query
- `apps/server` — Fastify, Socket.IO, Prisma, PostgreSQL, Redis
- `packages/shared` — типы, расчёт синхронизации, права, фильтр сообщений

Без `DATABASE_URL` сервер держит данные в памяти. Для постоянного хранения поднимите Postgres и Redis.

## Запуск

Нужен Node.js 22 или новее.

```bash
npm install
npm test
```

На Windows дважды нажмите `start-sinc.bat`. Откроются два окна: сервер и Expo. Оба должны оставаться открытыми. Чтобы остановить их, дважды нажмите `stop-sinc.bat`.

Вручную это те же две команды в разных терминалах:

```bash
npm run dev:server
npm run dev:mobile
```

Дальше в окне Expo нажмите `w`. Приложение откроется в браузере, обычно на http://localhost:8081. Сервер отвечает на http://localhost:4000/health.

На экране «Как к вам обращаться?» введите имя и нажмите «Продолжить». Затем «Демо-ролик Big Buck Bunny» и «Создать комнату». Это открытый ролик Blender Foundation, не фильм из каталога. Чтобы увидеть синхронизацию, откройте ту же комнату по 6-значному коду во втором окне браузера.

Пока сервер запущен, `node scripts/smoke.mjs` проверяет комнату, синхронизацию, отказ DRM и лимит бесплатного плана.

### Телефон

Магазинный Expo Go сейчас не открывает SDK 58: в App Store лежит клиент для SDK 54. На iPhone этот проект через Expo Go не запустится, смотрите его в браузере. На Android можно поставить Expo Go для SDK 58 со страницы https://expo.dev/go и отсканировать QR-код из окна Expo. Телефон и компьютер должны быть в одной Wi-Fi.

Если приложение на телефоне не видит сервер, создайте `apps/mobile/.env` с адресом компьютера в сети:

```bash
EXPO_PUBLIC_API_URL=http://192.168.1.10:4000
```

Для эмулятора Android обычно `http://10.0.2.2:4000`.

### Postgres и Redis

```bash
docker compose up -d
```

Скопируйте `.env.example` в `.env` в корне и раскомментируйте:

```bash
DATABASE_URL=postgresql://sinc:sinc@localhost:5432/sinc
REDIS_URL=redis://localhost:6379
JWT_SECRET=длинный-случайный-секрет
```

Затем:

```bash
npm run db:push --workspace @sinc/server
npm run dev:server
```

## Как устроена синхронизация

Клиент считает ожидаемую позицию по часам сервера:

```ts
expected = positionSec + elapsedSec * playbackRate
```

Пока пауза или идёт трёхсекундный отсчёт внешнего режима, позиция не двигается. Сдвиг часов берётся из ping/pong с учётом половины задержки, а не из наивного сравнения локальных часов.

Если расхождение больше 0.6 секунды, клиент делает seek. Если меньше — мягко меняет скорость в диапазоне 0.97–1.03. На экране в этот момент только плашка «Подгоняем время…».

Во внешнем режиме `play` превращается в «Все нажимают Play сейчас», `seek` — в «Перемотайте на 01:12:30». Точность покадровая не обещается.

Обрыв связи: сокет переподключается с экспоненциальной паузой, команды стоят в очереди, последняя комната лежит в AsyncStorage. Звонок и блокировка экрана ставят локальное видео на паузу и после возврата подгоняют его к серверу, не останавливая всю комнату.

## Что заложено, но не включено в MVP

- Голос через LiveKit: `POST /api/rooms/:code/voice` отвечает, что комнат ещё нет
- Файлы в R2/S3: загрузка проверяет план Pro и отвечает, что хранилище не подключено
- Push: напоминания за 30 и 5 минут пишутся в очередь и пока логируются. Сюда подключаются FCM и APNs
- Оплата: в профиле есть `plan: free | pro` и пробный переключатель без биллинга
- Apple и Google sign-in не делались, вход — почта или гость

## Деплой

Образ сервера собирается из корневого `Dockerfile`.

- **Fly.io:** `fly.toml` уже в корне. `fly launch` / `fly deploy`, секреты `DATABASE_URL`, `REDIS_URL`, `JWT_SECRET`. Для Socket.IO нужна одна машина или Redis-адаптер — он включается, если задан `REDIS_URL`.
- **Railway:** новый сервис из Dockerfile, те же переменные и Postgres/Redis плагины.
- **Приложение:** из `apps/mobile` команда `npx eas-cli@latest build --profile preview`. Схема `sinc://room/{code}`, универсальная ссылка `https://sinc.app/r/{code}`. Для неё на домене нужен `apple-app-site-association` и `assetlinks.json`.

Expo Go может отставать от SDK 58. Тогда смотрите в веб (`w` в терминале Expo) или соберите development build.
